# Mohamed Laaribi — Portfolio

[View the live portfolio](https://mohamedlaaribi.me/)

A static portfolio highlighting applied machine learning, NLP, and software engineering projects. It supports English, French, and Arabic, and includes light and dark themes.

## Preview locally

Run `python -m http.server 8000` from the repository root and open `http://localhost:8000/`. The HTML, CSS, and JavaScript are already built.

## Publish

GitHub Pages serves the root of `main`. The `CNAME` file configures `mohamedlaaribi.me`.

- `index.html` contains the featured projects and page content.
- `output.css` contains the checked-in styles.
- `main.js` handles language, theme, navigation, contact, and metadata for selected repositories from GitHub’s public API.
- `mohamed-laaribi-portfolio-source.zip` contains the original source package.

The contact form opens a prefilled email draft in the visitor’s email app.
